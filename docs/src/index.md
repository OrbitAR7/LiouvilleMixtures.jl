# LiouvilleMixtures.jl

Entropy accounting for Gaussian and Gaussian-mixture uncertainty propagation
on volume-preserving orbital flows.

The package is being built milestone by milestone. This page will document
the dynamics and tensor propagation (M1), the entropy and KL tools (M2), and
the negentropy predictor (M3) as they land.
